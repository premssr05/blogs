Confounding

At its simplest, a confounder is an observed variable (Z) that causally influences both the treatment (X) and the outcome (Y)

To understand Practical way to identify confounders we need to understand back-door path and criterion

Back-door path

a non-causal path between (X) and (Y) that has an arrow pointing into the treatment

The Backdoor Criterion

The backdoor criterion, introduced by Judea Pearl, is used to determine a set of variables Z that, when controlled for, allow for an unbiased estimate of the causal effect of a treatment X on an outcome Y from observational data

More formally, a variable is a confounder if it lies on an open backdoor path between the treatment and the outcome. It acts as the central node of a "fork" on that backdoor path.
